# NORMECO 产线方案素材交接说明

本目录用于另一台电脑上传 `solutions.html` 所需的正式图片、视频、规格参数、CAD/布局图和项目案例。上传前请阅读根目录 `WORK_LOG.txt` 中的“Codex 接续检查点（2026-08-28）”。

## 建议目录

```text
assets/solutions/
├─ hero/               整线主视觉、整体渲染、整体运行视频
├─ socket-changer/     自动切换多工位套筒
├─ robot/              工业机器人
├─ spindle/            拧紧轴及控制器
├─ applications/       三个典型应用场景
└─ documents/          参数表、布局图、公开版 CAD/PDF
```

目录可以在上传资料时创建。网页最终引用的文件名统一使用英文小写和短横线，例如：

```text
hero/robot-tightening-cell.webp
socket-changer/socket-changer-front.webp
socket-changer/socket-change-demo.mp4
robot/robot-working-envelope.webp
spindle/tightening-spindle-front.webp
applications/mixed-model-line.webp
documents/socket-changer-specification.xlsx
```

## 第一优先级：页面必须素材

### 1. 首屏整线主视觉

- 横向整线照片、3D 渲染图或清晰 CAD 总装截图 1–3 张。
- 推荐比例 16:10 或 16:9，宽度至少 2000 px。
- 可选 10–40 秒横向运行视频，内容包含机器人、换套筒、拧紧和复位中的至少两个动作。

### 2. 自动切换多工位套筒

- 正面、侧面、45 度、安装状态、套筒工位和传感器细节照片。
- 机器人取用、归还或换套筒视频。
- 参数：正式名称/型号、工位数量、支持规格、接口、换型时间、检测与防错方式、尺寸、重量、安装方式、电气/气源需求、工作环境、兼容机器人和拧紧轴。

### 3. 工业机器人

- 本体图、安装状态、末端安装拧紧轴照片、工作半径图。
- 参数：品牌、型号、轴数、负载、臂展、重复定位精度、安装方式、防护等级、控制器和通讯接口。

### 4. 拧紧轴

- 轴体、控制器、接口、机器人安装状态及可公开的拧紧曲线界面。
- 参数：品牌、型号、扭矩范围、转速、扭矩/角度精度、输出接口、拧紧策略、控制器、通讯协议、数据记录能力、尺寸、重量和防护等级。

### 5. 三个应用场景

- 多型号混线生产：不同产品共线或型号切换照片。
- 多规格螺栓装配：同一工件不同规格紧固件及自动换套筒照片。
- 大型结构件拧紧：大型工件、分散点位或复杂角度照片。
- 每个场景至少 1 张横向图片，并附 2–4 句真实项目说明。

## 第二优先级：增强资料

- 公开版 STEP/STP、DWG/DXF、PDF 布局图或安装尺寸图。
- 可公开项目案例、节拍和验收结果。
- 专利、认证、检测报告及合作品牌授权素材。
- 工件照片、螺栓规格、点位数量、目标扭矩、节拍、工位空间、PLC/MES 接口等典型工况资料。

## 文件限制和公开要求

- GitHub 普通仓库单文件上限为 100 MB；网页视频建议每个不超过 50 MB。
- 视频优先使用 H.264 MP4；图片优先使用高质量 JPG、PNG 或 WebP。
- 高清原片可以保留在本地，仓库内只提交网页优化版。
- 未经确认，不提交客户名称、客户 Logo、未脱敏控制界面、保密图纸、敏感 CAD 或真实生产数据。
- 参数未知时标记“待确认”或“按项目确定”，不得由 Codex 推测或编造。

## 上传后的 Codex 任务

1. 执行 `git status -sb`，只识别本次新上传的产线资料。
2. 汇总文件、尺寸、格式、缺失参数和公开风险。
3. 在 `WORK_LOG.txt` 追加上传日期、文件清单和仍缺资料。
4. 将原始素材转换为网页版本，保留原文件，不覆盖用户资料。
5. 替换 `solutions.html` 中的 Hero、产品和场景占位框。
6. 更新中英文产品文案，只使用已确认参数。
7. 本地验证桌面端、移动端、中英文、视频加载和交互后再提交。
